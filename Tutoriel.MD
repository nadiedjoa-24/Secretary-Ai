### Pour copier un fichier de votre machine locale vers le GPU, utilisez la commande `scp` avec la syntaxe suivante :

`scp localisation_du_fichier identifiant_telecom@gpuN.enst.fr:~`

### Explication de la commande :
- `localisation_du_fichier` : le chemin du fichier à copier depuis votre machine locale (ex. : `/chemin/vers/fichier/audio.mp3`).
- `identifiant_telecom` : votre identifiant utilisateur sur le serveur.
- `gpuN.enst.fr` : l'adresse du serveur distant avec N l'identifiant correspondant.
- `:~` : le répertoire de destination sur le serveur distant. Ici, il s'agit du répertoire personnel de l'utilisateur.
